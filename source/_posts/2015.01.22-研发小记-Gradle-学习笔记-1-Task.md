新建一个文件夹, 在里面编辑 build.gradle

```gradle doLast
task hello {
    doLast {
        println 'Hello world!'
    }
}
```

```bash
$ gradle -q build
Hello world!
```

---

```gradle doLast的简化写法
task hello << {
    println 'Hello world!'
}
```

```bash
$ gradle -q build
Hello world!
```

---

```gradel Use String Lower&Upper
task string << {
    String someString = "mY_nAme"
    println "Original: " + someString
    println "Lower case: " + someString.toLowerCase()
    println "Upper case: " + someString.toUpperCase()
}
```

```bash
$ gradle -q build
Hello world!
```
