## 安装 ddns

Openwrt 系统应该是预装了 ddns，小云 OS 没有预装 ddns，我们可以通过 opkg 装上 ddns

- 配置 opkg
  可参考 [Newifi Mini(Y1) 动手玩(2) - opkg](/2015/10/09/82aa8fa67de7.html)

- 在管理页面搜索 `ddns`

![](/img/post/2015.10.09/1.png)

- 安装 `ddns-scripts` 和 `luci-app-ddns`

安装完成即可在 服务中找到动态 DNS 页面 <!-- more -->

## 启动 ddns

系统 -> 启动项 -> 启动`ddns`

![](/img/post/2015.10.09/2.png)

## 配置 ddns

- 我们需要选择一个 ddns 服务商，这里推荐 3322.org (http://www.pubyun.com/ )，注册后创建一个动态域名。
- 后台配置
  ![](/img/post/2015.10.09/3.png)

```
主机名：即刚刚创建的动态域名
用户名：3322.org 用户名
密码：3322.org 密码
```

- 重启路由器

## 自定义域名

使用 3322 的二级域名当然不能满足我们的要求，要如何实现自定义域名呢？

- 注册域名
- 在你的 DNS 服务商添加一个`CNAME`映射到`动态域名`中

![](/img/post/2015.10.09/4.png)

## 常见问题

### 为什么完成上面步骤还是不能使用自定义域名访问呢？

1. 检查防火墙设置
   ![配置成此图即可](/img/post/2015.10.09/5.png)
2. 检查 IP 端口是否被关闭
   使用 [端口扫描](http://tool.chinaz.com/port) 查看 80 端口是否被关闭，如果关闭，我们可以换个端口

```sh vi/etc/config/dropbear
    # 原始数据
    config uhttpd 'main'
        list listen_http '0.0.0.0:80'
        list listen_http '[::]:80'
        ...
        ...

    # 修改为
    config uhttpd 'main'
        list listen_http '0.0.0.0:8080'
        list listen_http '[::]:8080'
        ...
        ...
```

    修改保存后，重启uhttpd服务

```sh
    /etc/init.d/uhttpd restart
```

### 安全问题

路由器密码不要使用弱密码，如果路由器被黑客入侵，密码安全就没有保障了。ssh 应该关闭密码登录使用密钥登录。
