## 开启 SSH

使用 SSH 免密登录

本机：

1. 使用`ssh-keygen`生成 SSH 公钥
2. 查看公钥`cat ~/.ssh/id_rsa.pub`

<!-- more -->

服务器：

1. 新建文件夹

```bash
mkdir /root/.ssh
```

2. 写入本机的 SSH 公钥

```bash
vim /root/.ssh/authorized_keys
```

3. 关闭密码登录

```bash
vim /etc/ssh/sshd_config

找到 PasswordAuthentication yes
改成 PasswordAuthentication no

service sshd restart
```

测试：

```bash
ssh root@192.168.1.2
```
