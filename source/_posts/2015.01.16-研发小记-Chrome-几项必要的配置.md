## 自定义 Css

1. 新建一个文件夹，比如 Custom CSS，包含 Custom.css 和 manifest.json 两个文件
2. manifest.json 的内容如下

```json
{
  "content_scripts": [
    {
      "css": ["Custom.css"],
      "all_frames": true,
      "matches": ["http://*/*", "https://*/*"]
    }
  ],
  "description": "Custom.css",
  "name": "Custom CSS",
  "version": "1.0",
  "manifest_version": 2
}
```

3. 打开 Chrome 的扩展管理，选择打包扩展程序，扩展程序根目录选择 Custom CSS 文件夹，私有密匙文件不用管，然后选择打包扩展程序，生成 Custom CSS.crx 和 Custom CSS.pem。
4. 将 Custom CSS.crx 拖入扩展管理安装即可。

## chrome://flags/

1. overlay-scrollbars : 使用自动收起的滚动条，不占用额外空间(全平台)
2. enable-smooth-scrolling : 像 Mac 和手机一样平滑滚动(仅 Linux 可用)
3. enable-download-resumption : 恢复下载

## 取消 Flash P2P 上传功能

> 国内的视频网站大都会 P2P 上传，往往会把上传带宽吃满，导致网络卡顿，可以把这个功能禁用掉

1. 打开`/Users/{}/Library/Application Support/Google/Chrome/Default/Pepper Data/Shockwave Flash` 目录
2. 在下面创建一个 System 的新目录，然后在里面创建一个 mms.cfg 文件
3. 写入 RTMFPP2PDisable=1
4. 保存，然后重启 Chrome
