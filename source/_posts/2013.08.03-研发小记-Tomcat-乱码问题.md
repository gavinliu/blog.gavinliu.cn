1. Myeclipse 启动 Tomcat 控制台乱码：
   window -> Preference -> myeclipse -> servers -> tomcat -> tomcat7.0 -> JDK -> optional java VM arguments :加入 -Dfile.encoding=GBK
2. 接受数据乱码，设置字符集什么都不管用时：
   修改 Tomcat 的 server.xml
   ```xml
   <Connector port="8080" protocol="HTTP/1.1"
            connectionTimeout="20000"
            redirectPort="8443"/>
   ```
   ```xml
   <Connector port="8080" protocol="HTTP/1.1"
            connectionTimeout="20000"
            redirectPort="8443" URIEncoding="UTF-8" />
   ```
